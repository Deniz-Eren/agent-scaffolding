## Purpose

Record the third-party open-source software, files, snippets, and libraries that {{PROJECT_NAME}} uses. Give the license attribution and the compliance notices.

## Structure

Two numbered sections group the entries. Section 1 lists copied files and snippets in the repository. Section 2 lists external dependencies and build tools. Each entry gives a short summary with the source, the license type, and the function or file path of the component. Add an optional Section 3 for trademarks when necessary.

## Formatting Rules

- Do not copy full license text blocks into this document. Write a short summary of the license type. Give the license name or SPDX identifier, the copyright holder, and a link to the license text or upstream repository.
- In Section 1 (copied files and snippets), record `Component(s) Used`, `Source`, and `Source License` as a short summary.
- In Section 2 (dependencies and build tools), record `Function`, `Source`, and `License` as a short summary.
- Do not erase entries. Add an entry when you add a third-party component, and keep source URLs accurate.
